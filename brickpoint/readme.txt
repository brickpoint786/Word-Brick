Production-ready WordPress + Elementor Pro theme for BrickPoint — premium bricks & construction materials — with a one-click demo importer.

== Description ==
* Faithful conversion of the original BrickPoint design (colours, typography, spacing, cards, animations, responsive behaviour).
* Custom post types: Products (bp_product), Videos (bp_video), Projects (bp_project), Locations (bp_location) + blog.
* WhatsApp ordering on every product (no WooCommerce).
* 21 BrickPoint Elementor widgets + 18 template widgets, BrickPoint dynamic tags, BrickPoint icon library.
* Elementor Pro Theme Builder header, footer, single/archive templates and 404 with display conditions (imported as JSON).
* One-click demo importer: Appearance → BrickPoint Demo → Import Demo (repeatable, no duplicates).

== Installation ==
1. Appearance → Themes → Add New → Upload Theme → brickpoint.zip → Activate.
2. Install & activate Elementor (and Elementor Pro for Theme Builder header/footer/archives).
3. Appearance → BrickPoint Demo → Import Demo. Wait for "BrickPoint Demo Imported Successfully".
4. Edit contact/WhatsApp/social details under Appearance → Customize → BrickPoint.

The theme works without Elementor too: every page, archive and single is rendered by the PHP templates with the same design.
